# Lot for Sale Landing Page

A lightweight Next.js landing page for a property listing in Daraga, Albay.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. Replace the property photo placeholder in `app/page.tsx` with an image from `public/`.
2. Replace `YOUR-EMAIL@example.com` with the actual inquiry email.
3. Add the exact lot area and price if you want those details public.
4. Add phone, Messenger, or WhatsApp links as needed.
5. Deploy the GitHub repository to Vercel.

The Google Maps directions button is already configured for:
`13.159478303269635, 123.72196217620163`
